# 核心观点

家庭不是单个成员的相加，而是一套长期互动形成的关系系统。

# 系统解释

家庭系统塑造一个人如何理解爱、责任、边界和冲突。很多个体问题并不只属于个体，而是关系结构长期运转后的结果。

# 现实案例

一个总是替别人负责的人，可能来自边界不清的家庭结构；一个害怕表达需求的人，可能曾在亲密关系中反复被否定。
