# 林峰系统 v0.1.0 发布说明

## 发布时间

2026-05-28

## 当前版本

`v0.1.0`

## 线上地址

https://clf-personal-2026.vercel.app/

## 当前阶段

MVP

## MVP 功能

- 首页：林峰系统论入口页，展示 `BEING YOURSELF｜成为你自己` 与五大系统入口。
- 认知地图：以国、族、家、企、人五大系统组织知识节点。
- 知识节点库：支持静态搜索、系统筛选、标签筛选与节点详情跳转。
- 知识节点详情：展示定义、核心观点、系统解释、案例、视频化表达与延伸阅读。
- 视频内容数据库：管理视频选题、状态、关联节点、平台、大纲、脚本片段与复盘信息。
- 专题路径：组织推荐阅读路径与关联视频选题。
- 后台管理系统：提供知识节点、视频选题、专题、标签、系统结构与 Obsidian 内容源的管理入口。
- Markdown 内容系统：支持 `content/nodes` 标准 Markdown 节点读取。
- Obsidian 同步预留：提供 dry-run 同步脚本，暂不写入 Supabase。
- Supabase 架构预留：提供 schema、seed、客户端与查询封装。
- Vercel 部署准备：完成部署文档、预部署检查脚本与线上部署验证。

## 已知限制

- 后台表单目前是静态占位，不会真实保存。
- 暂未启用 Supabase 写入。
- 暂未启用登录、鉴权和后台权限控制。
- Markdown 同步脚本当前只支持 dry-run，不会写入数据库。
- 知识节点前台数据源当前优先读取 Supabase；未配置 Supabase 时回退到 Markdown，再回退到 Mock。
- 视频选题与专题仍主要使用 Mock 数据，未来再接入 Supabase。
- 搜索为前端静态搜索，暂未接入全文搜索索引。

## 下一阶段路线图

- 启用真正 Supabase 写入。
- 接入登录权限与后台访问控制。
- 增加 AI 内容生成能力，用于知识节点、视频选题与脚本辅助生产。
- 建立内容关系图谱，强化节点、专题、视频之间的结构化关联。
- 搜索增强，支持更完整的全文检索与权重排序。
- 自动化同步，从 Obsidian Markdown 到 Supabase，再到前台内容展示闭环。
